# Deviations from the project brief

[PROJECT_BRIEF.md](PROJECT_BRIEF.md) was the plan. This is what changed while building it, and
why. "Approved" means approved by the maintainer. "Second-pass review" means a review by a
separate Claude session, the same model that wrote the code, so it is not an independent review.
